How it was measured

yolo11n_raspberry_executorch_optimized.pte (4.73 MB, input 640) on ExecuTorch/XNNPACK: 37.8 ms mean inference (p95 42.9 ms), 26.48 FPS inference only, 24.2 FPS end to end, peak RAM 969 MB. No network used. Only counts leave the device; no faces or frames are stored in deploy mode.

Limits

  • Tracked totals link boxes by overlap only and over-count in crowds; per-frame counts count the same person in every frame.
  • The road zone and the BUSY/JAMMED cut-offs are set by hand for each site.
  • Small or half-hidden people are missed; the error against a human count is stated above when measured. Head blur in saved frames covers only detected people, so a missed person is not blurred.

What this is for

A ward engineer leaves this box at a school gate for a week and reads one page: at which times, if any, people and traffic share the road.
